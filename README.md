# E-commerce Database Design

Team database project for CSE 3330 (Database Systems & File Structures) at UT Arlington, Fall 2026.

- **Phase 1 (done):** ER/EER model for an online store: customers, wishlists (modeled as a weak entity with a partial key and identifying relationship), and their relationships and participation constraints. See [`phase1-er-eer-design.pdf`](phase1-er-eer-design.pdf).
- **Phase 2 (in progress):** mapping the design to a relational schema and implementing it in SQL.

> Built as UT Arlington coursework. If you're taking the course, please don't copy it for your own submission.
